    - Issue: Uses polling (inefficient, battery drain, delayed messages)
    - Impact: Poor UX, server load, costs
    - Current: Polls every 5 seconds
    - Fix: Implement Socket.IO (you already have useSocket hook!)
  4. Conversation Creation Flow
    - Issue: Users can't start conversations - only through "Contact Seller" button on product page
    - Impact: Limited messaging initiation

    - Issue: Backend uses validator.escape() which converts special characters to HTML entities
    - Impact: Messages may show &quot; instead of ", &lt; instead of <

    - Fix: Use XSS protection library that doesn't escape quotes, or unescape on frontend
